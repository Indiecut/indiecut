# Security policy

## Supported versions

Security fixes are applied to the latest release on the default branch (`main`).
Older packaged builds may not receive backports.

## Reporting a vulnerability

**Do not open a public GitHub issue** for security vulnerabilities.

Please report them privately using one of these options:

1. **GitHub private vulnerability reporting** — use **Security → Report a vulnerability** on this repository (preferred when enabled)
2. **Email** — contact the maintainers via the address listed on [indiecut.io](https://indiecut.io) or the GitHub organization profile if private reporting is unavailable

Include:

- A clear description of the issue
- Steps to reproduce or a proof of concept
- Affected version / commit and OS if relevant
- Impact assessment if you have one

## What to expect

- We will acknowledge receipt when we can
- We will investigate and work on a fix before any public disclosure
- Please give us reasonable time to patch before discussing the issue publicly

Thank you for helping keep IndieCut and its users safe.
